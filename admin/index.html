Підключення до GitHub

Адмінка зберігає пости й проєкти прямо у ваш репозиторій. Для цього потрібен токен доступу:
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → репозиторій сайту.
  3. Permissions → Repository → Contents: Read and write.
  4. Скопіюйте токен і вставте нижче. Він зберігається лише в цьому браузері.
