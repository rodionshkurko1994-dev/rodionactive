Project X

Браузерна гра: збиття повітряних цілей над Україною в єдиному спільному світі для всіх гравців.

Відкрити сайт ↗

Ідея

Небо над Україною, яке живе власним життям: цілі летять цілодобово, час від часу стаються масовані атаки. Кожен гравець бачить ті самі цілі в тих самих точках, а збиває їх сам, розставляючи власні комплекси ППО.

Що всередині

  • спільний світ: розклад цілей обчислюється з часу, тож він однаковий для всіх гравців без окремого ігрового сервера;
  • кілька типів загроз (БпЛА, крилаті ракети, балістика) і чотири класи комплексів — від мобільної вогневої групи до ЗРК великої дальності, з різним радіусом, влучністю та ціною боєприпасу;
  • жорстка економіка: кошти заробляються лише збиттями і не відновлюються з часом;
  • реєстрація й вхід за електронною поштою, рейтинг гравців, стійкість міст і журнал подій;
  • захист від накруток: постріли, купівлі й нарахування коштів рахує серверна функція, а браузер лише показує результат;
  • окрема адмінка: ручний запуск цілей, масована атака, список гравців зі статистикою.

Технології

Статичний фронтенд на GitHub Pages з власним доменом projectx.vision, база даних, авторизація та серверна логіка — на Supabase (PostgreSQL, правила доступу, Edge Functions).
